# kintore-pen

自分用の筋トレ記録PWA。メニュー（B1／B2／A／日課）を選ぶと種目ごとにセット行が出るので、重量とレップを入れて「記す」を押す。記録は GitHub の private リポジトリ **nikki** の `training/` に Markdown で直接コミットされる。

- データはこのリポジトリには一切入らない。ここにあるのは皮（UI）だけ
- 認証は nikki-pen と**同じ** Fine-grained PAT（nikki 限定・Contents 読み書き）。端末の localStorage にのみ保存
- 圏外時はローカルにキューし、次回オンライン起動時に自動送信
- ホスティング: GitHub Pages（静的1ページ）

## セットアップ

1. GitHub Pagesを有効化（Settings → Pages → Deploy from a branch → main / root）
2. iPhoneのSafariでPages URLを開く → 共有 → **ホーム画面に追加**
3. 初回起動時に設定が開くので、nikki-pen と同じ Fine-grained PAT を貼る（ホーム画面アプリの側で貼る。Safariとはストレージが別）

## 使い方（v1）

- **メニュー**: 上のタブで B1（上半身）／B2（下半身）／A（軽い日）／日課 を選ぶ。定義は Balthier `MISSION/life/筋トレと食事_研究調査レポート.md`（2026/3/22 改訂）と `トレーニングログ.md` の日課
- **種目カード**: 目標レンジ（例 `8〜12回 × 3`）と**前回**（例 `前回 8/24: 26×12 · 33×12 · 33×10`）を表示。重量は前回値で埋まっているので**レップだけ打てばいい**。前回が全セット上限なら「今回 +2.5〜5kg」のヒントが出る
- **セット**: レップが入った行だけ記録される（空行＝やらなかった）。`＋ セット` で行追加、`×` で削除。重量を打つと後ろの空行にも同じ値が流れる
- **追加**: 任意種目のチップ（リアデルトイド等）、または「その他 ▾」から店のマシンを追加。自由入力もあり
- **日付**: 右上。朝4時までは前日扱い。過去日にも書ける（未来は不可）
- **下書き**: 入力は自動で端末に残る。ジムで途中閉じても消えない。メニューごとに別々に保持
- **記す**: `training/YYYY-MM-DD-HHmmss.md` を PUT。同日複数回OK（日課＋B1など）

## 出力フォーマット

`トレーニングログ.md` と同じ表。そのまま貼り付けて合流できる。

```markdown
## 2026/8/31（月）— B1（上半身）

### 筋トレ

| 種目 | セット | 重量 | レップ |
|------|--------|------|--------|
| ラットプルダウン | 1 | 26kg | 12 |
| | 2 | 33kg | 12 |

### メモ

- 33kgは2セット目からきつい
```

日課は `| 種目 | 回数 |` の2列。

## 前回値の出どころ

- 起動時・復帰時に nikki の `training/` 一覧を取り、直近20件を読んで種目ごとの最新セットを組み直す（ファイル単位で localStorage にキャッシュ。二度読みしない）
- `training/` にまだ無い種目は、`トレーニングログ.md` の最新実績（2026/3 時点）を初期値として同梱

## 送信まわりの挙動（nikki-pen v1.2 と同じ）

- GitHubがエラーを返したときは理由をトーストで出し、入力は残す。**圏外（通信自体が失敗）のときだけ**キューに入れる
- 起動時・復帰時・オンライン復帰時に未送信分を再送する
- 新しい版は起動時・復帰時に取り込み、下書きが無ければ自動で読み直す
